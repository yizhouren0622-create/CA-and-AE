参考方向、功率与元件Reference directions, power and elements

第1章 · §1-2 电路变量；§1-4 电阻元件

电压和电流的参考方向由你选定，求得负值表示实际方向相反。先判断电流参考箭头是否进入电压标记的正端，再选功率式。关联方向下，正功率表示吸收；负功率表示供出。电源也可能吸收功率。Choose reference directions before calculating. A negative result reverses the actual direction. First check whether the reference current enters the labeled positive terminal. Under the passive sign convention, positive power is absorbed and negative power is delivered. A source can absorb power.

pabs=ui(passive sign convention)
pabs=−ui(opposite convention)
u=Ri,pR=i2R=u2R

解题顺序Solution process

  1. 在图上标出电流箭头与电压正负端，不先猜实际方向。Label current arrows and voltage polarity before guessing the actual direction.
  2. 写出关联或非关联功率关系；电阻的欧姆定律也必须与参考方向一致。Write the power relation for the chosen convention. Match the resistor law to the reference directions.
  3. 把单位统一到 V、A、Ω 后计算；最后写明吸收或供出。Use V, A and ohms consistently; state whether power is absorbed or delivered.
不能看到“电源”就认定供电，也不能看到负电流就判供出功率。功率取决于电压、电流和两者参考方向。A source symbol does not prove that power is delivered. A negative current alone does not determine the power sign. Use voltage, current and their reference directions together.
一分钟检查One-minute check
关联方向 u=−6V、i=2A：吸收功率 −12W，即供出 12W。With passive references, u=−6V and i=2A give absorbed power −12W, so 12W is delivered.

KCL、KVL与图论计数KCL, KVL and topology

第1章；2.1–2.3 · §1-3 基尔霍夫定律；§2-1～§2-3

KCL约束节点电流，KVL约束闭合路径电压。连接结构先于元件数值。对连通图，选定参考节点后有 n−1 个独立KCL方程，独立回路数为 b−n+1。交叉导线只有明确连接时才算同一节点。KCL constrains node currents and KVL constrains voltages around closed paths. Topology comes before component values. A connected graph has n−1 independent KCL equations and b−n+1 independent loops. Crossing wires form one node only when connected.

∑iout=0,∑loopu=0
NKCL=n−1,Nloop=b−n+1

解题顺序Solution process

  1. 把由理想导线连接的点合并成节点，数清支路与节点。Merge points joined by ideal wires into nodes and count branches.
  2. KCL统一取流出为正；KVL先固定绕行方向。Use one KCL sign convention and choose a loop traversal direction.
  3. 支路电流法以支路电流为未知量，补齐元件伏安关系，检查独立方程数是否足够。For branch-current analysis, add element relations and check the number of independent equations.
重复列写所有节点KCL会产生冗余方程。电阻所在支路的电压正负号取决于绕行方向，不能只抄电源符号。Writing KCL at every node adds a redundant equation. Resistor voltage signs depend on the loop traversal; source polarity alone is insufficient.
一分钟检查One-minute check
连通网络 n=4、b=6：独立节点方程3个，独立回路方程3个。For a connected graph with n=4 and b=6: three independent node equations and three independent loop equations.

电源、等效变换与受控源Sources, transformations and dependent sources

第1章 · §1-5～§1-9

理想电压源规定端电压，理想电流源规定支路电流。源变换保持端口的伏安特性，不保证内部电流和功率逐项相同。受控源的控制量是电路未知量的一部分，必须保留控制关系。An ideal voltage source fixes terminal voltage; an ideal current source fixes branch current. A source transformation preserves terminal behavior, not every internal current or power. A dependent source requires its controlling equation.

Is=UsR,Rseries=Rparallel
u=μux,i=gux,u=rix,i=βix

解题顺序Solution process

  1. 确认电压源串联电阻，或电流源并联电阻，且对外只有同一对端口。Identify a voltage source in series with a resistance or a current source in parallel with it.
  2. 标清转换后电源方向，使开路电压和短路电流一致。Choose transformed source direction to preserve open-circuit voltage and short-circuit current.
  3. 遇受控源先写控制量；求等效电阻时只置零独立源。Write the dependent-source control relation. Zero only independent sources when finding equivalent resistance.
不能把独立电压源“置零”成开路。电压源置零是短路，电流源置零是开路；受控源不置零。A zero independent voltage source is a short; a zero independent current source is an open. Dependent sources remain active.
一分钟检查One-minute check
12V 串联3kΩ的端口等效为4mA并联3kΩ；电流源方向应使原正端为正。A12V source in series with 3kilohms is terminal-equivalent to 4mA in parallel with 3kilohms, oriented to preserve the original positive terminal.

节点电压法与网孔法怎么选Choosing nodal or mesh analysis

2.4–2.5 · §2-4 节点电压法；§2-5 网孔分析法

比较未知量数量和源的类型。节点少、电流源多时常选节点法；平面网络且网孔少时可选网孔法。没有与参考节点相连的理想电压源不能直接用电导表示，可增加源电流未知量和电压约束，或使用超节点。Compare unknown counts and source types. Few nodes and many current sources favor nodal analysis. A planar network with few meshes may favor mesh analysis. A floating ideal voltage source needs an extra current unknown and a voltage constraint, or a supernode.

∑kVa−VkRak=Iinjected
Va−Vb=Us
Rshared(I1−I2)(same mesh orientation)

解题顺序Solution process

  1. 选参考节点，优先让尽可能多的已知电压源一端接参考地。Choose a reference node, preferably connected to known voltage sources.
  2. 逐条支路写电流，明确流出与注入方向；受控量化成节点电压。Write each branch current with a consistent direction; express control quantities in node voltages.
  3. 求解后用另一个节点或全电路功率平衡复核。After solving, check a different node or the total power balance.
网孔法只直接适用于平面电路；共享电阻电流通常是两个网孔电流之差。不能把每个闭合路径都当成独立网孔。Direct mesh analysis requires a planar circuit. Shared resistor current is usually the difference of mesh currents. Not every closed path is an independent mesh.
一分钟检查One-minute check
节点接12V经2kΩ、接地经4kΩ、另有1mA注入时：(V−12)2k+V4k=1m，V=283V。For a node connected to 12V through 2kilohms, ground through 4kilohms, and a1mA injection: (V−12)2k+V4k=1m, giving V=283V.

叠加、戴维南与最大功率Superposition, Thevenin and maximum power

3.1–3.5 · §3-1～§3-5

线性电路先判断所求量是电压或电流还是功率。叠加适用于线性响应，功率不能直接叠加。戴维南法适合研究同一端口负载变化：先求开路电压，再求从端口看到的等效电阻。Determine whether the requested quantity is a linear voltage and current response or power. Superposition applies to linear responses, not directly to power. Thevenin analysis is useful for changing a load at a fixed port: find open-circuit voltage, then the resistance seen into the port.

UTh=Uoc,RTh=UtestItest
IL=UThRTh+RL
RL=RTh>0,Pmax=UTh24RTh(resistive load)

解题顺序Solution process

  1. 明确端口与负载，卸下负载求开路电压。Identify the port and remove the load to find open-circuit voltage.
  2. 置零独立源，保留受控源。需要时向端口施加测试源。Zero independent sources, retain dependent sources and apply a test source if needed.
  3. 接回负载求电压电流，功率最后计算；最大功率公式要求正的戴维南电阻及可调纯电阻负载。Reconnect the load; compute power last. The resistive matching formula assumes positive Thevenin resistance and an adjustable resistive load.
受控源存在时不能随手按串并联求等效电阻。开路电压、短路电流法遇到00时应改用测试源。Do not casually reduce a dependent-source network as passive resistors. If the open and short ratio becomes 00, use a test source.
一分钟检查One-minute check
Uth=8V、Rth=43kΩ 时，匹配负载为43kΩ，最大功率12mW。For Uth=8V and Rth=43kilohms, the matched load is 43kilohms and maximum power is 12mW.

储能元件、换路与初值Storage elements, switching and initial values

5.1–5.4 · §5-1 电容；§5-2 电感；§5-3 忆阻；§5-4 换路

电容记住电压，电感记住电流。无冲激电流或电压时，换路瞬间电容电压与电感电流连续。电容电流与电感电压可以跳变。直流稳态下，理想电容开路、理想电感短路。A capacitor retains voltage and an inductor retains current. Without impulsive current or voltage, capacitor voltage and inductor current are continuous at switching. Capacitor current and inductor voltage may jump. At DC steady state, an ideal capacitor is open and an ideal inductor is short.

iC=CduCdt,uL=LdiLdt
WC=12CuC2,WL=12LiL2
uC(0+)=uC(0−),iL(0+)=iL(0−)(no impulses)

解题顺序Solution process

  1. 画换路前长期稳态电路，求uC(0−)、iL(0−)。Draw the pre-switch DC steady-state circuit and find the storage variables.
  2. 用连续性得到0+储能状态；在0+电路中用相应电压源或电流源替代储能元件求其他量。Transfer continuous states to 0+. Replace the storage element by its initial voltage and current constraint to find other quantities.
  3. 忆阻元件按课件给定的状态关系处理，不能把所有具有记忆的元件都当线性电阻。Use the stated state relation for a memristive element; it is not automatically a linear resistor.
“电容电压连续”不等于“任何电容支路电流都连续”。存在理想冲激激励时必须回到积分形式判断。Continuous capacitor voltage does not imply continuous capacitor current. With ideal impulses, check the integrated element equations.
一分钟检查One-minute check
10μF电容电压从2V变到10V，储能增加0.48 mJ。A10 microfarad capacitor changing from 2V to 10V gains 0.48 mJ of stored energy.

一阶电路的三要素与分段响应First-order responses and piecewise switching

5.5–5.9 · §5-5～§5-9

把动态问题化成初值、终值和时间常数。零输入响应来自初始储能，零状态响应来自外加激励，两者相加得到全响应。多次换路时，每段末值成为下一段初值，时间变量从该段起点重新计。Reduce a first-order transient to initial value, final value and time constant. Zero-input response comes from stored energy; zero-state response comes from excitation. Their sum is the total response. At each later switching time, carry forward the previous final state and restart elapsed time.

x(t)=x(∞)+[x(0+)−x(∞)]e−tτ
τRC=ReqC,τRL=LReq

解题顺序Solution process

  1. 先求储能状态初值，再求换路后长期稳态终值。Find the initial storage state and post-switch final steady state.
  2. 只置零独立源，从储能元件端口求Req；受控源保留。Zero independent sources and find the resistance seen by the storage element, retaining dependent sources.
  3. 写三要素式，再代t=0和t→∞检验；需要其他变量时由KCL、KVL或微分关系求出。Write the response and check t=0 and infinity. Derive other variables using KCL and KVL or element derivatives.
时间常数取换路后的网络。三要素指数式要求该时间段为线性一阶、参数恒定、外加激励恒定且有限终值存在；不能直接套在持续正弦或斜坡激励上。Use the post-switch network. This three-parameter exponential requires a linear first-order interval, constant parameters, constant excitation and a finite final value. Do not apply it directly to ongoing sinusoidal or ramp excitation.
一分钟检查One-minute check
u0=2V、u∞=10V、τ=20ms时，u(τ)=10−8e≈7.057V。For u0=2V, u∞=10V and τ=20ms, u(τ)=10−8e≈7.057V.

相量、阻抗与交流解题Phasors, impedance and AC analysis

7.1–7.6 · §7-1～§7-6

相量法把同频正弦稳态的微分运算变成复数代数。本站统一使用余弦参考和有效值相量。先把所有源变成同一约定，再把R、L、C转为阻抗，随后复用节点法或戴维南法。Phasors turn same-frequency sinusoidal steady-state differential equations into complex algebra. This site uses cosine reference and RMS phasors. Convert all sources to the same convention, replace RLC by impedances, then reuse nodal or Thevenin methods.

u(t)=2Ucos(ωt+ϕ) ⟺ U―=Uejϕ
ZR=R,ZL=jωL,ZC=1(jωC)
I―=U―Z

解题顺序Solution process

  1. 把sin换成cos时相位减90°；峰值除以√2得到有效值。Converting sine to cosine subtracts 90 degrees; divide peak amplitude by 2 for RMS.
  2. 乘除优先极坐标，加减必须转直角坐标。Polar form is convenient for multiplication and division; use rectangular form for addition and subtraction.
  3. 结果回到时域时乘√2，并核对电感电流滞后、电容电流超前。Multiply by 2 when returning to the time domain. Check inductor lag and capacitor lead.
不能把不同频率的相量放进同一方程。课程只列到7.6，7.7起功率章节不进入默认考试卷。Do not combine different-frequency phasors in one equation. The plan stops at §7.6, so the later AC-power sections are excluded from default exam papers.
一分钟检查One-minute check
Z=6+j8Ω，U=10∠30°V，则I=1∠−23.130°A（有效值）。For Z=6+j8ohms and U=10 angle 30 degrees V, I=1 angle −23.130 degrees A RMS.

RC频率特性：只先掌握概念RC frequency response: conceptual bridge

电路第10章合讲；模电6.1概念 · §10-1、§10-2；ch06.pptx 第1–9页

频率响应问同一电路对不同频率的正弦信号怎样改变幅值和相位。RC低通从电容取输出，低频通过；RC高通从电阻取输出，高频通过。截止处幅值为通带值的12，约−3dB。Frequency response describes amplitude and phase changes as sinusoidal frequency varies. An RC low-pass takes output across C; an RC high-pass takes output across R. At the cutoff, magnitude is 12 of the passband value, approximately −3dB.

HLP(jω)=1(1+jωRC)
HHP(jω)=jωRC(1+jωRC)
fc=1(2πRC)

解题顺序Solution process

  1. 先看输出取在哪个元件上，不按电路画法猜低通或高通。Identify which element carries the output.
  2. 分别用ω→0和ω→∞检验输出极限。Check the low- and high-frequency limits.
  3. 本节作为频域概念桥梁；不把未明确要求的高阶频率计算加入默认试卷。Treat this as a conceptual bridge; do not infer advanced frequency-analysis exam requirements.
−3dB对应幅度约0.707，不是0.5。电路第10章的详细考试深度尚未在纲领中明确。−3dB corresponds to amplitude about 0.707, not 0.5. The detailed examination depth of Circuit Chapter 10 is not specified.
一分钟检查One-minute check
低通电路频率越高，电容阻抗越小，电容两端输出越小。For a low-pass output across C, increasing frequency reduces capacitor impedance and therefore output voltage.
