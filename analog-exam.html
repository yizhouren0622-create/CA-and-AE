1. 加载后的源电压增益1. Loaded source-to-output gain

10分10 points

信号源vs=10mV，内阻Rs =2kΩ。放大器输入电阻Ri=8kΩ，空载电压增益Av0=−20，输出电阻Ro =1kΩ，负载RL=4kΩ。求vi、vo和源电压增益。A10mV source has Rs =2kilohms. The amplifier has Ri=8kilohms, unloaded voltage gain −20 and Ro =1kilohm. With RL=4kilohms, find vi, vo and source-to-output gain.

提示Hint
输入和输出各有一次分压。Include an input divider and an output divider.
答案、步骤与检查Answer, working & checks
  1. vi=10mV·8(2+8)=8mV。vi=10mV·8(2+8)=8mV.
  2. 空载输出=−20(8)=−160mV；带载vo=−160·4(1+4)=−128mV。Unloaded output is −160mV; loaded vo=−160·4(1+4)=−128mV.
  3. Avs=vovs=−12.8。Avs=vovs=−12.8.

vi=8mV，vo=−128mV，Avs=−12.8。vi=8mV, vo=−128mV, Avs=−12.8.

两次分压均为0.8，0.8×(−20)×0.8 = −12.8。评分：输入3分，输出4分，总增益3分。Both dividers are 0.8, so 0.8×(−20)×0.8 = −12.8. Rubric: input 3, output 4, overall gain 3.

2. 反相放大与饱和检查2. Inverting amplifier and saturation check

10分10 points

理想运放同相端接地，输入经10kΩ接反相端，100kΩ反馈电阻接输出到反相端。假设可用输出范围±12V，输入vi=0.2V。求vo、Rin支路输入电流及保持线性时|vi|的上限。An ideal op-amp has its non-inverting input grounded, Rin =10kilohms and Rf =100kilohms. Assume output limits ±12V. For vi=0.2V, find vo, Rin branch current and maximum |vi| for linear operation.

提示Hint
负反馈线性时反相节点为虚地；输出需在±12V内。Under linear negative feedback the inverting node is virtual ground; check ±12V output limits.
答案、步骤与检查Answer, working & checks
  1. 线性候选解v−=v+=0，输入电流i=(0.2−0)10k=20μA。Candidate linear solution: v−=v+=0, so input current is 20μA.
  2. KCL：(0−vi)10k+(0−vo)100k=0，得vo=−10vi=−2V。KCL gives (0−vi)10k+(0−vo)100k=0, hence vo=−10vi=−2V.
  3. |vo|≤12给|vi|≤1.2V；实际保持严格线性应避开边界。|vo|≤12 implies |vi|≤1.2V; stay inside the boundary for strict linear operation.

vo=−2V，Rin支路输入电流20μA；理想边界|vi|=1.2V。 理想运放输入管脚电流为0。vo=−2V, Rin branch current 20 microamps; ideal input boundary |vi|=1.2V. The ideal op-amp input-pin current is zero.

反馈电阻电流同为20μA，候选输出未饱和。评分：虚短条件2分，KCL与vo4分，电流2分，范围2分。Feedback current is also 20 microamps and the candidate output is unsaturated. Rubric: regime 2, KCL and output 4, current 2, limits 2.

3. 积分器及初值3. Integrator and initial condition

10分10 points

理想反相积分器输入电阻10kΩ、反馈电容0.1μF，同相端接地，输出初值0V。t=0后输入1V直流。假设输出在±10V内线性。求2ms时输出和到达−10V的理想时间。An ideal inverting integrator has R=10kilohms, feedback C=0.1 microfarad, grounded non-inverting input and initial output 0V. A1V DC input begins at t=0. Assume linear swing ±10V. Find output at 2ms and the ideal time to −10V.

提示Hint
RC=1ms；恒定输入产生负斜率。RC=1ms; constant positive input produces a negative output slope.
答案、步骤与检查Answer, working & checks
  1. RC=104·10−7=10−3s。RC=10−3s.
  2. vo(t)=0−t(10−3)V=−1000tV（t以秒计，尚未饱和）。vo(t)=−1000tV with t in seconds, until saturation.
  3. vo(2ms)=−2V；−1000t=−10给t=10ms。vo(2ms)=−2V and the ideal boundary time is 10ms.

2ms时−2V；10ms到达负输出边界，之后不延伸线性斜坡。−2V at 2ms; reaches the negative boundary at 10ms, after which the linear ramp cannot continue.

电阻输入电流0.1mA，经反馈电容产生−1000Vs斜率。评分：RC2分，含初值关系4分，两结果各2分。The 0.1mA input current gives −1000Vs through the feedback capacitor. Rubric: RC2, initial-value relation 4, each result 2.

4. 二极管状态验算4. Diode state consistency

10分10 points

5V理想源经1kΩ串联二极管接地，先使阳极接电阻、阴极接地。采用0.7V恒压降模型，求电流。再将二极管反接，假定反向击穿电压大于5V，求电流并验证截止条件。A5V source feeds a diode through 1kilohm to ground, initially with anode at the resistor and cathode grounded. Use a0.7V constant-drop model. Find current. Reverse the diode, assume breakdown above 5V, then find current and check cutoff.

提示Hint
导通解检查电流为正；截止解检查阳极对阴极电压。Check positive current for an on-state and anode-to-cathode voltage for cutoff.
答案、步骤与检查Answer, working & checks
  1. 正接假定导通：ID=(5−0.7)1k=4.3mA>0，状态成立。Forward candidate: ID=(5−0.7)1k=4.3mA>0, consistent.
  2. 反接假定截止：ID=0，电阻无压降，阴极5V、阳极0V，vD=−5V。Reversed candidate: ID=0; cathode is at 5V and anode at 0V, so vD=−5V.
  3. 反向电压未达到给定击穿条件，截止成立。The reverse voltage is below the stated breakdown condition, so cutoff is consistent.

正接4.3mA，反接0；反接时vD=−5V。Forward 4.3mA; reversed zero, with vD=−5V.

正接KVL 4.3+0.7=5V。评分：模型2分，正接3分，反接3分，状态检查2分。Forward KVL: 4.3+0.7=5V. Rubric: model 2, forward 3, reverse 3, validation 2.

5. 稳压管电流预算5. Zener current budget

10分10 points

稳压电路Vi=12V，经R=1kΩ接输出；输出并联RL=5kΩ与反向稳压管。采用VZ=5V恒压模型，正常稳压要求1mA≤IZ≤10mA。求IR、IL、IZ、PZ，并求保持稳压的输入电压范围。A Zener regulator has Vi=12V, series R=1kilohm, RL=5kilohms and a reverse Zener across the output. Use VZ=5V with regulation requiring 1mA≤IZ≤10mA. Find currents, Zener power and allowable Vi range.

提示Hint
IR=IL+IZ；输入范围用IZ两端限制。IR=IL+IZ; use the two Zener-current limits for Vi.
答案、步骤与检查Answer, working & checks
  1. IR=(12−5)1k=7mA，IL=55k=1mA。IR=7mA and IL=1mA.
  2. IZ=6mA，PZ=5(6mA)=30mW，电流在范围内。IZ=6mA, giving PZ=30mW; current is within limits.
  3. VI=VZ+R(IL+IZ)，故7V≤VI≤16V。VI=VZ+R(IL+IZ) gives 7V≤VI≤16V.

IR=7mA，IL=1mA，IZ=6mA，PZ=30mW；Vi范围7–16V。IR=7mA, IL=1mA, IZ=6mA, PZ=30mW; Vi range 7–16V.

上下边界分别代回得到1与10mA。评分：三电流4分，功率2分，范围与验证4分。Substitute both voltage boundaries to recover 1 and 10mA. Rubric: currents 4, power 2, range and validation 4.

6. NMOS静态与交流6. NMOS DC and small-signal analysis

10分10 points

增强型NMOS源极接地，栅极直流3V，漏极经2kΩ接12V。VT=1V，规定ID=K(VGS−VT)2且K=1mAV2，忽略沟道调制。交流时栅极直接加微小信号vi，漏极通过足够大的耦合电容接2kΩ负载。求Q点、验证工作区，再求gm和中频电压增益。An enhancement NMOS has grounded source, DC gate 3V and drain through 2kilohms to 12V. Let VT=1V and ID=K(VGS−VT)2, K=1mAV2, with no channel modulation. A small AC input drives the gate; a large coupling capacitor connects a2kilohm drain load. Find bias, validate saturation, then find gm and midband voltage gain.

提示Hint
直流负载电阻被耦合电容隔离；交流RD与RL并联。The coupling capacitor isolates RL for DC; RD and RL are parallel for AC.
答案、步骤与检查Answer, working & checks
  1. VOV=2V，IDQ=1(2)2=4mA。VOV=2V and IDQ=4mA.
  2. VDSQ=12−(4mA)(2k)=4V≥2V，恒流区成立。VDSQ=12−(4mA)(2k)=4V≥2V, confirming saturation.
  3. gm=2KVOV=4mS，Av=−gm(2k∥2k)=−4。gm=4mS and Av=−gm(2k∥2k)=−4.

IDQ=4mA，VDSQ=4V，gm=4 mS，Av=−4。IDQ=4mA, VDSQ=4V, gm=4 mS, Av=−4.

漏极直流KVL为8+4=12V；小信号电流增量乘1kΩ得到反相增益。评分：Q点4分，工作区2分，gm2分，增益2分。DC KVL: 8+4=12V; incremental current through 1kilohm gives the negative gain. Rubric: bias 4, region 2, gm2, gain 2.

7.BJT偏置的精确加载7.BJT bias with base loading

10分10 points

NPN共射电路VCC=12V，RC=2kΩ，RE=1kΩ。基极偏置网络戴维南等效为2.7V串联20kΩ。取β=99，VBE=0.7V，忽略Early效应。求IB、IC、IE、VC、VE、VCE，并验证放大区。An NPN common-emitter circuit has VCC=12V, RC=2kilohms and RE=1kilohm. Base bias is Thevenin-equivalent to 2.7V in series with 20kilohms. Use β=99, VBE=0.7V and no Early effect. Find IB, IC, IE, VC, VE and VCE, then validate forward-active operation.

提示Hint
不要把基极电流当0；发射极电流是(β+1)IB。Do not neglect base current; IE=(β+1)IB.
答案、步骤与检查Answer, working & checks
  1. IB=(2.7−0.7)[20k+100(1k)]=16.6667μA。IB=(2.7−0.7)[20k+100(1k)]=16.6667μA.
  2. IC=1.65mA，IE=1.66667mA。IC=1.65mA and IE=1.66667mA.
  3. VE=1.66667V，VC=12−1.65(2)=8.7V，VCE=7.03333V。VE=1.66667V, VC=8.7V and VCE=7.03333V.
  4. VB=VE+0.7=2.36667V，VC>VB；BE正偏且BC反偏，放大区成立。VB=2.36667V and VC>VB; BE is forward biased and BC reverse biased.

IB=16.667μA，IC=1.65mA，IE=1.6667mA；VC=8.7V，VE=1.6667V，VCE=7.0333V。IB=16.667 microamps, IC=1.65mA, IE=1.6667mA; VC=8.7V, VE=1.6667V and VCE=7.0333V.

基极回路0.3333+0.7+1.6667=2.7V。评分：基极方程3分，电流2分，节点电压3分，工作区2分。Base-loop check: 0.3333+0.7+1.6667=2.7V. Rubric: base equation 3, currents 2, voltages 3, region 2.

8. 有限增益与深负反馈近似8. Finite gain and deep-feedback approximation

10分10 points

采用负反馈约定xi =xid+xf，xf= Fxo，xo = Axid。A=1000，F=0.09，均为无量纲且频率无关。求精确闭环增益、深负反馈近似，并以精确值为基准算近似相对误差。Use negative-feedback convention xi =xid+xf, xf= Fxo and xo = Axid. Let A=1000 and F=0.09, dimensionless and frequency-independent. Find exact closed-loop gain, deep-feedback estimate and relative error referenced to the exact value.

提示Hint
先由三个关系消去xid和xf，再比较1F。Eliminate xid and xf, then compare with 1F.
答案、步骤与检查Answer, working & checks
  1. xo=A(xi−Fxo)，所以Af=A(1+AF)=100091≈10.98901。xo=A(xi−Fxo) gives Af=100091≈10.98901.
  2. AF=90，近似Af≈1F=1009≈11.11111。AF=90, so the approximation is 1F=1009≈11.11111.
  3. 相对误差[(1009)−(100091)](100091)=190≈1.1111%。The relative error is 190≈1.1111%.

精确10.9890；近似11.1111；相对误差1.1111%。Exact 10.9890; estimate 11.1111; relative error 1.1111%.

将Af乘(1+AF)应回到A；别把1.11%写成0.0111%。评分：关系推导3分，精确3分，近似2分，误差2分。Af(1+AF) must recover A. Distinguish a fraction 0.01111 from 1.111%. Rubric: derivation 3, exact 3, estimate 2, error 2.

9. 一阶有源低通9. First-order active low-pass

10分10 points

已知理想有源低通传递函数H(s)=2(1+sRC)，R=10kΩ，C=10nF。求截止频率、截止处幅值和相位。再说明两个隔离的一阶低通级与未缓冲的两个RC网络为何不能总用同一乘积。An ideal active low-pass has H(s)=2(1+sRC), R=10kilohms and C=10nF. Find cutoff, magnitude and phase at cutoff. Explain why multiplying two isolated first-order stages is not generally equivalent to two unbuffered RC networks.

提示Hint
截止处ωRC=1；独立级相乘需要不相互加载。At cutoff ωRC=1; stage multiplication assumes no interstage loading.
答案、步骤与检查Answer, working & checks
  1. RC=10−4s，fc=1(2πRC)≈1591.549Hz。RC=10−4s and fc≈1591.549Hz.
  2. H(jωc)=2(1+j)=1−j，所以|H|=2、相位−45∘。H(jωc)=1−j, so magnitude is 2 and phase is −45∘.
  3. 隔离级可以相乘；未缓冲RC的下一级输入阻抗改变上一级，因此必须分析整体网络。Isolated stages may be multiplied. An unbuffered second RC stage loads the first, requiring analysis of the full network.

fc≈1.592kHz；|H|=1.4142，相位−45°；级间加载需计入。fc about 1.592kHz; |H|=1.4142 and phase −45 degrees; include interstage loading.

相对通带2的幅度比为0.7071，而绝对幅度为1.4142。评分：fc3分，幅相4分，加载解释3分。Relative to passband 2, the ratio is 0.7071 while absolute magnitude is 1.4142. Rubric: fc3, magnitude and phase 4, loading 3.

10. 迟滞比较器与概念边界10. Hysteresis comparator and concept checks

10分10 points

理想反相迟滞比较器：信号vi接反相端，同相端v+=0.2vo，输出电平±10V。求上门限、下门限、回差；说明从vi=−3V逐渐上升到3V时如何翻转。最后判断：两个差分输入都增加同样的Δ属于共模还是差模？An ideal inverting Schmitt trigger has vi at the inverting input, v+=0.2vo and output levels ±10V. Find upper and lower thresholds and hysteresis. Track vi increasing from −3 to +3V. Finally, if both differential inputs increase by the same delta, is that common- or differential-mode?

提示Hint
分别由当前高输出和低输出算反馈门限；不要全程用虚短。Compute thresholds for each output state; do not apply a virtual short throughout.
答案、步骤与检查Answer, working & checks
  1. 高输出时v+=2V，输入上升越过+2V时输出由+10翻到−10V。With output high, v+=2V; increasing vi past +2V switches +10 to −10V.
  2. 低输出时v+=−2V，输入下降越过−2V时输出由−10翻到+10V。With output low, v+=−2V; decreasing vi past −2V switches −10 to +10V.
  3. 回差2−(−2)=4V。从−3V上升时先高，越过+2V后低。Hysteresis is 4V. Increasing from −3V starts high and switches low past +2V.
  4. 两个输入同增Δ使差值不变，属于共模变化；仅需概念判断。Equal input increments leave their difference unchanged: common-mode change, assessed conceptually.

上门限+2V，下门限−2V，回差4V；上升越过+2V翻低；同增量属于共模。Thresholds +2 and −2V, width 4V; rising past +2V switches low; equal increments are common-mode.

门限之间输出依历史，等号处不指定唯一稳态。评分：两门限4分，回差2分，路径2分，共模2分。Between thresholds the output depends on history; equality does not specify a unique steady state. Rubric: thresholds 4, width 2, path 2, common-mode 2.
