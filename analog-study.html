信号、放大器与输入输出负载Signals, amplifiers and loading

1.1、1.3–1.5 · ch01.pptx 第1–24页，跳过1.2

先分清直流偏置、交流信号、输入端和信号源端。放大器的电压增益vovi，与源电压增益vovs不同；输入电阻与源内阻分压，输出电阻与负载再次分压。Separate DC bias, AC signal, amplifier input and source terminals. Voltage gain vovi differs from source-to-output gain vovs. Source resistance and input resistance form one divider; output resistance and load form another.

vi=vsRi(Rs+Ri)
vo=Av0viRL(Ro+RL)
AdB=20log10|Av|(voltage ratio)

解题顺序Solution process

  1. 把题目要的增益写成明确的电压比，标出两个测量端口。Write the requested gain as an explicit voltage ratio at labeled ports.
  2. 画输入和输出等效模型，再计入负载。Draw input and output equivalent models and include loading.
  3. 讨论带宽时区分幅度值与分贝值；信号频谱1.2不列入范围。Distinguish magnitude from decibels when discussing bandwidth; §1.2 spectra is outside scope.
不要把空载增益直接当带载源电压增益。只有同一类电压幅度比才直接用20log10。Unloaded gain is not loaded source-to-output gain. Apply 20log10 to consistent voltage-amplitude ratios.
一分钟检查One-minute check
输入分压0.8、空载增益−20、输出分压0.8，则总源增益−12.8。With input divider 0.8, unloaded gain −20 and output divider 0.8, total source-to-output gain is −12.8.

理想运放：先判断工作状态Ideal op-amps: decide the operating regime

第2章全部 · ch02.pptx 第14–38页

理想运放输入电流为零。虚短还要求电路处于稳定负反馈的线性工作区，不能无条件套在开环比较器或已饱和电路上。先求候选线性解，再与供电及输出限制核对。An ideal op-amp draws zero input current. A virtual short additionally requires stable negative-feedback linear operation. It cannot be applied unconditionally to open-loop comparators or saturated circuits. Calculate a candidate linear solution, then check output limits.

i+=i−=0,v+≈v−(linear negative feedback)
Ainv=−RfRin
Anoninv=1+RfRg

解题顺序Solution process

  1. 检查输出是否反馈到反相端，并判断该反馈是否负反馈。Identify the feedback path and determine its sign.
  2. 用虚短确定输入节点电压，用虚断在节点列KCL。Use equal input voltages and zero input current to write node KCL.
  3. 解出输出后检查是否超出可用输出摆幅；超限时改按饱和状态分析。Check the computed output against available swing. If it exceeds the limits, analyze saturation instead.
虚地只有在另一输入端接地且虚短成立时出现。运放输出电流不为零，反馈支路和负载都要计入。Virtual ground requires a grounded opposite input and a valid virtual short. Op-amp output current is not zero; it includes feedback and load currents.
一分钟检查One-minute check
Rin =10kΩ、Rf=100kΩ、vi=0.2V：vo=−2V；若输出允许±12V，候选解未超限。With Rin =10kilohms, Rf=100kilohms and vi=0.2V: vo=−2V, within assumed ±12V output limits.

求和、求差、积分与微分Summing, subtraction, integration and differentiation

2.4 · ch02.pptx 第40–58页

识别输入电阻和反馈元件，再从KCL推关系，比死记电路轮廓可靠。多输入运放可以叠加，但最终仍须检查输出范围。电容在输入端或反馈端的位置决定微分或积分。Identify the input and feedback elements, then derive KCL rather than memorizing the drawing. Superposition can handle multiple inputs, but output limits still apply. A capacitor in the input versus feedback path distinguishes differentiation from integration.

vo=−Rf∑kvkRk
vo(t)=vo(0)−1RC∫0tvi(ξ)dξ
vo=−RCdvidt

解题顺序Solution process

  1. 在求和节点列各输入电流和反馈电流。Write input and feedback currents at the summing node.
  2. 求差电路先求同相端的分压，再列反相端KCL；只有电阻比匹配时才化为纯差模比例式。For subtraction, first find the non-inverting divider voltage. A pure difference expression requires matched resistor ratios.
  3. 积分题保留初值；微分题先区分理想阶跃与真实有限上升时间。Keep the integrator initial condition; distinguish ideal steps from finite rise times in differentiators.
理想积分器恒定输入会使输出持续变化，最后可能饱和。不能无限延伸理想线性斜坡。A constant input drives an ideal integrator continuously and may cause saturation. Do not extend a linear ramp indefinitely.
一分钟检查One-minute check
RC=1ms、vi=1V、vo(0)=0：2ms时vo=−2V，须仍在线性输出范围内。For RC=1ms, vi=1V and vo(0)=0: vo(2ms)=−2V, provided the output remains within its linear range.

PN结与二极管：假设后要验算PN junctions and diode state validation

第3章全部 · ch03.pptx 第16–38、41–71页

PN结由多子扩散、空间电荷区和内建电场形成；热平衡时扩散与漂移电流抵消。电路题先选理想、恒压降或小信号模型。分段线性分析必须先假设导通状态、求候选解，再检验状态不等式。APN junction involves majority-carrier diffusion, a depletion region and a built-in field. At thermal equilibrium, diffusion and drift currents cancel. Choose the ideal, constant-drop or small-signal model first. Assume states, solve, then verify the corresponding inequalities.

iD=IS(evD(nVT)−1)
vD=Vγ, iD≥0(on, constant-drop model)
iD=0, vD≤Vγ(off, same model)

解题顺序Solution process

  1. 标出阳极、阴极，定义vD=vA−vK，电流从阳极流向阴极为正。Label anode and cathode and define positive diode voltage and current.
  2. 从断开状态或直观电位关系开始假设，解线性电路。Assume a state based on open-circuit voltages, then solve the resulting linear circuit.
  3. 检查每只管的导通电流非负、截止电压不超过导通阈值；不满足时更换状态。Check nonnegative on-current and an off-voltage below the threshold. Revise inconsistent states.
0.7V是题目采用的模型值，不是所有二极管在所有电流下的精确常数。反向击穿不能与普通截止混为一谈。0.7V is a chosen model value, not an exact universal diode voltage. Reverse breakdown differs from ordinary cutoff.
一分钟检查One-minute check
5V经1kΩ正向接恒压降0.7V的二极管，电流4.3mA；反接且未击穿时电流0。A5V source feeding a forward 0.7V diode through 1kilohm gives 4.3mA; reversed below breakdown, current is zero.

稳压管与限流条件Zener regulation and current limits

3.5 · ch03.pptx 第63–71页

稳压管利用反向击穿区的近似恒压特性，但需要限流。总电阻电流分给负载与稳压管；负载改变时先检查稳压管是否仍有足够电流及是否超功耗。Zener regulation uses an approximately constant reverse-breakdown voltage and needs current limiting. Series-resistor current splits between the load and Zener. Check minimum Zener current and maximum dissipation whenever load or supply changes.

IR=(VI−VZ)R,IL=VZRL,IZ=IR−IL
PZ=VZIZ,IZ,min≤IZ≤IZ,max

解题顺序Solution process

  1. 先假定稳压成立令vo=VZ。Assume regulation and set vo=VZ.
  2. 求IR、IL、IZ，并与允许电流范围核对。Calculate resistor, load and Zener currents, then check limits.
  3. 若IZ太小，改成未稳压电路求输出；若太大，指出模型虽有解但器件超限。If Zener current is too low, solve the unregulated circuit. If too high, identify device overstress.
不能把限流电阻电流全部当成稳压管电流。负载越重，稳压管分得的电流通常越少。Series-resistor current is not all Zener current. A heavier load usually leaves less current for the Zener.
一分钟检查One-minute check
Vi=12V、VZ=5V、R=1kΩ、RL=5kΩ：IR=7mA，IL=1mA，IZ=6mA。For Vi=12V, VZ=5V, R=1kilohm and RL=5kilohms: IR=7mA, IL=1mA and IZ=6mA.

MOSFET：静态工作区先于增益MOSFET bias before small-signal gain

4.1–4.5、4.7 · ch04.pptx 第3–52、55–97页及4.7

增强型NMOS首先判断栅源电压，再判断漏源电压。饱和区在放大电路中常称恒流区，与BJT饱和的意义不同。必须先求Q点并确认处于所假设工作区，才能由该点求gm和小信号增益。For enhancement NMOS, check gate-source voltage and then drain-source voltage. MOS saturation is the usual amplification region and differs from BJT saturation. Find and validate the bias point before deriving transconductance and small-signal gain.

VOV=VGS−VT,VDS≥VOV>0(NMOS saturation)
ID=K(VGS−VT)2,gm=2KVOV(this K convention)
Av≈−gm(RD∥RL∥ro)(source AC-grounded)

解题顺序Solution process

  1. 明确K的定义：有的书把12并入K，有的没有。State whether the factor 12 is included in K.
  2. 写直流KVL与器件方程，逐个候选根检查电压、电流和工作区。Solve DC KVL and the device law, then validate each candidate root and operating region.
  3. 画交流模型，电源交流接地、耦合电容按中频短路；求端口负载后的增益。Draw the AC model with supply at AC ground and midband coupling capacitors shorted. Include loading.
  4. 多级放大要先算下一级对上一级的加载，再乘各级实际增益。For cascaded stages, calculate interstage loading before multiplying actual stage gains.
不能把MOSFET恒流区与BJT饱和区混用。共漏近似同相、共栅近似同相，共源反相；精确增益仍取决于负载和源极电阻。Do not confuse MOS saturation with BJT saturation. Common drain and common gate are normally non-inverting; common source is inverting. Exact gains depend on loading and source resistance.
一分钟检查One-minute check
K=1mAV2、VT=1V、VGS=3V，得ID=4mA、gm=4 mS；还必须验证VDS≥2V。With K=1mAV2, VT=1V and VGS=3V: ID=4mA and gm=4 mS; VDS must still be at least 2V.

BJT共射：直流、模型、交流BJT common-emitter: DC, model, AC

5.1–5.3；排除教材小节5.2.5详细共集/共基放大，保留5.3性能比较 · ch05.pptx 第1–53页及5.3，排除共集/共基5.2.5

先检查发射结正偏、集电结反偏，建立放大区Q点。把基极偏置网络化为戴维南等效时，可保留基极电流引起的加载。交流计算使用该Q点对应的模型参数，不能把直流β、rbe与电阻档读数混同。Establish a forward-biased base-emitter junction and reverse-biased collector-base junction. A Thevenin bias equivalent can retain base-current loading. AC model parameters depend on the Q point; rbe is not simply an ohmmeter reading.

IB=VTh−VBERTh+(β+1)RE
IC=βIB,IE=(β+1)IB
VCE=VCC−ICRC−IERE
Av≈−β(RC∥RL)rbe+(β+1)RE(unbypassed emitter)
rbe=rbb′+(1+β)VTIEQ,Avs=AvRiRsi+Ri

解题顺序Solution process

  1. 直流电路中电容开路；直接接在集电极上的负载仍参与Q点，电容耦合负载不参与。求Q点并验两结偏置。Open capacitors for DC. A directly connected collector load remains in the bias circuit; a capacitor-coupled load does not. Solve Q and check both junctions.
  2. 区分发射极电阻是否被交流旁路，写清rbe采用的参数定义。Determine whether emitter resistance is bypassed for AC; state the rbe model.
  3. 把耦合和旁路电容按题目频段处理，计算Ri、Ro和带载增益。Handle coupling and bypass capacitors for the given band and compute loaded gain and port resistances.
  4. 若要求源增益，再乘输入分压。教材小节5.2.5共集、共基详细推导不在范围内；习题5.2.5偏置设计在范围内，5.3组态性能比较仍需掌握。For source gain,include input division. Detailed CCCB derivations in textbook section5.2.5 are excluded; exercise5.2.5 is included CE bias design,and section5.3 configuration comparisons remain required.
用两结偏置验工作区：NPN应VE<VB<VC，PNP相反；不能一看到负VCE就断言所有类型都失效。未旁路的RE须保留，求Ro时断开外接负载。未给小信号参数时，本项目按课件取rbb′≈200Ω、VT≈26mV并忽略厄利效应；数值需注明模型。Check both junctions: NPN needs VE<VB<VC; PNP reverses this order. Negative VCE alone does not invalidate aPNP active point. Retain unbypassed RE and remove the external load for Ro. Unspecified small-signal parameters use the course estimates rbb′≈200Ω,VT≈26mV and no Early effect; label these assumptions.

基极戴维南2.7V、20kΩ，RE=1kΩ、β=99、VBE=0.7V：IB=16.667μA。For base Thevenin 2.7V and 20kilohms, RE=1kilohm, β=99 and VBE=0.7V: IB=16.667 microamps.

频率响应与RC：仅概念Frequency response and RC: concepts only

第6章引言、6.1，仅概念 / Chapter 6 introduction and 6.1, concepts only · 教材第7版190–193页，图6.0.1、6.1.1、6.1.3；授课计划 / 7th ed., pp.190–193, Figs.6.0.1,6.1.1,6.1.3; course plan

频率响应同时描述增益幅度与相位随频率的变化。耦合、旁路电容主要决定低频衰减，小寄生及负载电容主要影响高频。RC输出取电容两端通常是低通，取串联电路的电阻两端通常是高通。放大器的中频区位于下限与上限之间；带宽需满足信号频带要求，但只说“在通带内”并不能保证严格无失真。Frequency response describes both gain magnitude and phase versus frequency. Coupling and bypass capacitors mainly affect the low-frequency end, while small parasitic and load capacitances affect the high-frequency end. An RC voltage output across the capacitor is typically low-pass; across the resistor in a series RC it is high-pass. An amplifier’s midband lies between lower and upper cutoffs. Bandwidth must cover the signal band, but passband membership alone does not guarantee exact waveform fidelity.

|Av(fL)|=|Av(fH)|=|AvM|2,BW=fH−fL
τ=RC,fc=12πτ
HLP(jω)=11+jωRC,HHP(jω)=jωRC1+jωRC

解题顺序Solution process

  1. 先标清输出取在哪里，再考察极低频和极高频的电容近似；不凭“有电容”判断滤波类型。Locate the output before using low and high-frequency capacitor limits; the presence of a capacitor alone does not identify the filter.
  2. 阅读幅频图：相对中频幅度下降约3dB的两点是上下限，幅度比为根号2的倒数，不能写成一半。Read magnitude plots: the lower and upper cutoffs are about 3dB below midband, with amplitude ratio the reciprocal square root of two, not one half.
  3. 阅读相频图：RC低通在转折处滞后45°，高通超前45°；这些是基础识别关系。Read phase plots: RC low-pass lags by 45 degrees at its corner; RC high-pass leads by 45 degrees. These are basic recognition relations.
  4. 结合电路分析已学的时间常数理解转折频率；此处公式用于建立概念联系，不把晶体管高频模型、米勒效应或多极点详细推导列作必考。Connect the corner frequency to the time constant learned in Circuit Analysis. The formulas support concepts; transistor high-frequency models, Miller effect and detailed multipole derivations are not required here.
幅度减半约为−6dB；同电阻条件下功率减半才约为−3dB。Hz与rads不可混用。电路第10章的具体计算深度尚未明确，不据此扩充考试要求。Halving amplitude is about −6dB; halving power at the same resistance is about −3dB. Distinguish hertz from radians per second. The calculation depth of Circuit chapter 10 remains unspecified and is not expanded by this guide.
一分钟检查One-minute check
中频幅度100、下限20Hz、上限20kHz：边界幅度约70.71，带宽19.98kHz；电容输出低通保留低频，电阻输出高通抑制直流。Midband magnitude 100, lower cutoff 20Hz and upper cutoff 20kHz give boundary magnitude about 70.71 and bandwidth 19.98kHz. Capacitor-output low-pass retains low frequencies; resistor-output high-pass rejects DC.

差分输入与共模抑制：仅概念Differential inputs and common-mode rejection: concepts only

7.2.1，仅概念 / Section 7.2.1, concepts only · 教材第7版233–234页，图7.2.1；授课计划 / 7th ed., pp.233–234, Fig.7.2.1; course plan

直接耦合会把静态漂移传到后级。对称差分结构以两路输入的差为有用量：共同变化在差分输出中相消。MOS源极耦合对的两管共用源节点和尾电流；匹配、足够的尾源输出电阻以及正确工作区是理想抑制的前提。单端输出与双端差分输出的共模表现不能混为一谈。Direct coupling passes bias drift to later stages. A symmetric differential structure amplifies input difference while common changes cancel in differential output. AMOS source-coupled pair shares a source node and tail current. Matching, adequate tail-source output resistance and valid operating regions are prerequisites for ideal rejection. Single-ended and differential-output common-mode behavior must be distinguished.

vid=v1−v2,vic=(v1+v2)2
v1=vic+vid2,v2=vic−vid2

解题顺序Solution process

  1. 定义差模为第一端减第二端，共模为两端平均；再用两式重构原输入。Define differential input as input 1 minus input 2 and common input as their average; reconstruct the original pair.
  2. 同增量属于共模；一增一减同样大小是纯差模；仅一端变化通常同时含两种分量。Equal increments are common-mode; equal opposite increments are purely differential. A single-input change usually includes both.
  3. 从对称性与总尾电流解释共同扰动的抑制，再指出失配、有限输出电阻和电压余量限制。Explain rejection through symmetry and tail-current constraint, then identify mismatch, finite output resistance and headroom limits.
  4. 考试路线只要求识别、分解和定性说明，不要求本章详细差分增益、共模抑制比或器件参数推导。The exam route requires recognition, decomposition and qualitative explanation, not detailed gain, CMRR or device-parameter derivations.
理想差分共模输出为零需要相应理想条件，不表示实际电路在任何输入电平下都抑制共模。不能把教材小节7.2.1直接当成同号习题的范围判定。Zero ideal differential output for common input requires the stated ideal conditions; actual rejection fails outside valid operating ranges. Subsection 7.2.1 does not automatically determine coverage of an exercise with the same number.
一分钟检查One-minute check
输入102mV与98mV：共模100mV、差模4mV；两端各增10mV只改变共模。仅第一端再增加2mV则共模增加1mV、差模增加2mV。Inputs 102 and 98mV give common mode 100mV and differential mode 4mV. Equal 10mV increments change only common mode. Increasing only input 1 by 2mV adds 1mV common mode and 2mV differential mode.

反馈分类与深度负反馈Feedback classification and deep negative feedback

8.1–8.4 · ch08.pptx 8.1–8.4

先用瞬时极性法判断反馈正负，再判断输入混合与输出取样方式。电压、电流取样和串联、并联混合组成四种反馈组态。开环增益、反馈系数和闭环增益必须采用相容的输入输出变量及单位。Use instantaneous polarity to determine feedback sign, then classify input mixing and output sampling. Voltage and current sampling and series and shunt mixing form four topologies. Open-loop gain, feedback factor and closed-loop gain must use compatible variables and units.

Af=A(1+AF)(negative-feedback convention)
|AF|≫1 ⟹ Af≈1F

解题顺序Solution process

  1. 人为令输入上升，沿前向链路与反馈链路追踪返回量，看它削弱还是增强净输入。Perturb the input and track the forward and feedback signals to see whether net input is reduced.
  2. 输入看反馈量是串联电压还是并联电流；输出用短路法等判断取样类型。Identify series-voltage versus shunt-current mixing and voltage versus current sampling.
  3. 检查深度负反馈条件后才用1F；最后从端口关系求题目要求的闭环电压增益。Use 1F only after checking deep-feedback conditions; then convert to the requested terminal voltage gain.

比较器与迟滞：不使用虚短Comparators and hysteresis

10.8.1 · ch10.pptx 第53–67页

比较器按差分输入符号输出高或低电平。迟滞比较器加入正反馈，门限随当前输出变化，两门限之间的输出取决于历史状态。翻转边界可以用输入相等求门限，但这不等于整个工作过程满足虚短。A comparator selects a high or low output according to the differential input sign. Positive feedback creates hysteresis: the threshold depends on the current output, so the state between thresholds depends on history. Equality at a switching boundary is not a continuous virtual short.

v+>v−⇒vo=VOH,v+<v−⇒vo=VOL
v+=βvo⇒VT+=βVOH,VT−=βVOL(inverting input signal)

解题顺序Solution process

  1. 标出信号输入端，判断输出与输入是同向还是反向翻转。Identify the signal input and switching direction.
  2. 分别假设当前输出为高和低，求对应反馈门限。Assume each output state and find its feedback threshold.
  3. 沿输入上升和下降分别追踪翻转；门限之间保留先前状态。Trace increasing and decreasing input separately; retain history between thresholds.
